Silent Failure — Query ID 18 · Pharmacology
Query: "What is the dosing adjustment for vancomycin in patients with renal impairment?"
The model ran for 5 minutes 0 seconds (confirmed from GIN log: 00:18:57, 5m0s) and returned zero output tokens. error: null — the failure was completely silent. No exception, no fallback, no partial output. In a clinical pipeline, this would silently drop a pharmacology query on a renally-dosed nephrotoxic antibiotic. Requires explicit empty-output detection and retry logic before production deployment.
⚠
Factual Hallucination — Query ID 82 · Clinical Trials · TOPAZ-1
Query: "Summarize the TOPAZ-1 trial findings on durvalumab in biliary tract cancer."
The model stated the trial was "stopped early for futility" and that durvalumab showed "no improvement in overall survival." This is factually inverted. TOPAZ-1 (NEJM, 2022) demonstrated that durvalumab + gemcitabine/cisplatin significantly improved overall survival vs. placebo in first-line BTC (HR 0.80, p=0.021), leading to FDA approval. The model conflated it with a failed second-line trial. This is a high-stakes error in a clinical AI context — a clinician querying treatment options for biliary tract cancer would receive actively incorrect guidance. Retrieval augmentation (RAG) is not optional for clinical trial queries.
◈
15% MBU — Memory Bandwidth Underutilization
The M4's unified memory bandwidth is 120 GB/s. At 15% MBU, the model is using ~18 GB/s. This is Ollama's single-sequence, non-batching architecture — there is no prefill/decode pipeline overlap, no continuous batching. The model is waiting between tokens. SGLang with RadixAttention or vLLM with PagedAttention will significantly improve this metric on the same hardware.
